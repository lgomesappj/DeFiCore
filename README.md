# DeFiCore

Decentralized-Chain Financial Gateway facilitates real-time, auto-scaling transactions and computations on a decentralized network platform.

With DeFiCore, you get a lightweight tool that stays out of your way.

**What you get**

- Decentralized-Chain Financial Gateway facilitates real-time,
- auto-scaling transactions and computations on
- a decentralized network platform

## Key Features

- Decentralized-Chain Financial Gateway facilitates real-time,
- auto-scaling transactions and computations on
- a decentralized network platform

## Technology Stack

- python
- python framework (Flask/Django/FastAPI or equivalent)
- Pytest for testing

## Installation

1. Clone the repository: `git clone https://github.com/harutosati/DeFiCore.git`
2. `cd DeFiCore`
3. Install in editable mode: `pip install -e .`

## Configuration

Most behavior is controlled via command-line flags:
- `--verbose`: enable detailed logging
- `--config <path>`: point to a custom config file
- `--dry-run`: preview changes without applying them
